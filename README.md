# Sobre o projeto

Projeto acadêmico desenvolvido durante o curso Java COMPLETO – Programação Orientada a Objetos + Projetos, do professor Nélio Alves, da plataforma DevSuperior.

Este projeto implementa um jogo de xadrez completo em Java, executado no terminal, aplicando fortemente os conceitos de Programação Orientada a Objetos (POO).

## Funcionalidades

O sistema implementa as regras oficiais do xadrez:

 Movimentação de todas as peças

 Validação de jogadas

 Captura de peças

 Controle de turnos

 Detecção de CHECK

 Detecção de CHECKMATE

Movimento especial Castling (Roque)

 Movimento especial En Passant

 Promoção de peão

 Tratamento de exceções personalizadas
